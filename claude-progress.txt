## Comparative Results (RERUN-2 / RERUN-3, 2026-05-19)

5-problem preview split, 5 attempts each, critic enabled (claude-haiku-4-5-20251001).
Full comparison report: results/comparison.md

| Metric              | Claude Sonnet 4.6 | Qwen3-235B (Cerebras) |
|---------------------|-------------------|-----------------------|
| pass@1              | 60.0%             | 0.0%                  |
| pass@5              | 60.0%             | 60.0%                 |
| pass@1 (human-solv) | 100.0%            | 0.0%                  |
| Brittle fraction    | 0.0%              | 40.0%                 |
| Total cost (USD)    | $25.44            | $8.59                 |

Per-problem breakdown:
- hb020 (Homo sapiens PDB):       Sonnet ✅ pass@1 | Qwen3 ✅ pass@5 only (1st attempt wrong)
- hb002 (Bacillus licheniformis): Sonnet ✅ pass@1 | Qwen3 ✅ pass@5 only (attempts 1,2,4 wrong)
- recqgsfxqqodhjens (CTCF motif): Sonnet ✅ pass@1 | Qwen3 ✅ pass@5 only (attempts 1-4 wrong)
- hb022 (pancreatic samples):     Both ❌ 0/5 (human_solvable=False)
- hb053 (heat stress):            Both ❌ 0/5 (human_solvable=False)

Key finding: Qwen3 solves the same 3 human-solvable problems as Sonnet when given 5 attempts,
but never on attempt 1 (pass@1=0%). Sonnet is consistently correct on first attempt for all
3 human-solvable problems (pass@1=100% on human-solvable subset). Qwen3 is 3× cheaper but
requires multiple attempts — high brittle fraction (40%) reflects this unreliability.

Earlier preview benchmark results (pre-fix harness, for reference):
- Claude Sonnet 4.6 (Anthropic): 80% pass@1 (from earlier run, without critic)
- llama-3.3-70b (Groq free tier): 20% pass@1 (1/5 — rest hit 100k token/day limit)
