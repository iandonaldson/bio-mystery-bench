## Pending slices

### RERUN-6: Qwen3/Cerebras benchmark run (validate all RERUN-5 remediations)

**Goal:** Run 5 preview problems × 5 attempts with Qwen3 on Cerebras, two-round critic
also on Qwen3/Cerebras. Compare results against RERUN-5 baseline using compare_runs.py.

**Pre-flight checklist (do before launching):**
1. Run `git pull origin main` to confirm on latest main.
2. Confirm CEREBRAS_API_KEY is set: `set -a && source .env && set +a`
3. Dry-run to check API key and cost estimate:
   `python scripts/run_eval.py --provider openai --api-base-url https://api.cerebras.ai/v1 --api-key "$CEREBRAS_API_KEY" --model qwen-3-235b-a22b-instruct-2507 --dataset preview --n-attempts 5 --max-steps 100 --dry-run`
4. Docker image rebuild: SI hash-gating will trigger automatically on first real run
   (all 5 skill files changed since last build). Explicit rebuild if preferred:
   `docker build -t bio-mystery-bench:latest -f docker/Dockerfile .`

**Run command:**
```bash
python scripts/run_eval.py \
  --provider openai \
  --api-base-url https://api.cerebras.ai/v1 \
  --api-key "$CEREBRAS_API_KEY" \
  --model qwen-3-235b-a22b-instruct-2507 \
  --critic-model qwen-3-235b-a22b-instruct-2507 \
  --critic-injection-points after_final_answer \
  --critic-injection-points after_critic_response \
  --max-critic-rounds 2 \
  --dataset preview \
  --n-attempts 5 \
  --max-steps 100
```

**Analysis steps after the run completes:**
1. Check `results/scores.json` for pass@1 and pass@5 per problem.
2. Run `python scripts/trajectory_to_md.py results/trajectories/` to generate Markdown summaries.
3. If a prior RERUN-5 results dir exists, run:
   `python scripts/compare_runs.py results/ <rerun5-results-dir>/`
4. For critic hallucination rate, check trajectories for critic responses that cite
   "Step N says: ..." (CITATION GATE enforcement) vs. uncited concerns.
5. Focus on hb002 (BLAST PATH issue), recq (genome download), and critic grounding.

**Expected improvements over RERUN-5:**
- hb002: blast-search SKILL (PATH warning) should stop agent bypassing blast_search tool
- recq: genome-retrieval SKILL + TM fixes should prevent premature download abandonment
- Critic: CA CITATION GATE should reduce hallucinated concern rate

**Definition of done:** run completes without harness errors; results/scores.json populated
for all 5 problems × 5 attempts; trajectory Markdown files generated.
