# results_version_0.2

First apples-to-apples benchmark comparison on the fully fixed harness.
Run date: 2026-05-19.

---

## Dataset

- **Source:** `Anthropic/BioMysteryBench-preview` (HuggingFace)
- **Split:** `preview` — 5 problems
- **Problems:** hb020, hb002, recqgsfxqqodhjens, hb022, hb053
  - hb020, hb002, recqgsfxqqodhjens: `human_solvable=True`
  - hb022, hb053: `human_solvable=False`

---

## Run parameters

Both runs used 5 attempts per problem, critic enabled.

### claude-sonnet-rerun/

```
python3 scripts/run_eval.py \
  --provider anthropic \
  --model claude-sonnet-4-6 \
  --critic-injection-points after_final_answer \
  --critic-model claude-haiku-4-5-20251001 \
  --results-dir results/claude-sonnet-rerun \
  --dataset preview --n-attempts 5
```

### cerebras-qwen3-rerun/

```
python3 scripts/run_eval.py \
  --provider openai \
  --api-base-url https://api.cerebras.ai/v1 \
  --api-key $CEREBRAS_API_KEY \
  --model qwen-3-235b-a22b-instruct-2507 \
  --judge-model claude-haiku-4-5-20251001 \
  --critic-injection-points after_final_answer \
  --critic-model claude-haiku-4-5-20251001 \
  --results-dir results/cerebras-qwen3-rerun \
  --dataset preview --n-attempts 5
```

## Code changes being tested (vs. earlier runs)

These results represent the first run after all of the following fixes were merged:

| Slice | PR | Description |
|-------|----|-------------|
| SC-1–4 | #40 | Fixed `_clean_answer()` stripping underscores from identifiers (e.g. `Sample_01`) |
| ENV-1–5 | #41 | Added `/opt/conda/bin` to container `PATH` so `python3`, `pip`, `bedtools` are on default shell path |
| SP-1–2 | #42 | System prompt: `rc=0` + empty stdout means no results, not tool absent; remote BLAST guidance |
| NR-1–2 | #42 | System prompt: transient network errors should be retried (30 s, up to 3×) |
| RL-1–5 | #43 | Rate-limit retry events logged to trajectory JSONL |
| RBfix-1–2 | #44 | `--resume` no longer re-runs `resource_abort` attempts, preventing corrupted `scores.json` totals |
| B-1–3 | #45 | `blast_search` tool added: BLAST results returned as compact top-N table, full output saved to scratch file |

Earlier preview runs (stored separately) were done before one or more of these fixes.
